# Bloom — Flower / Nature Website

A simple responsive course-project website about flowers.

## Included features

- Flower encyclopedia
- 8 flower entries
- Search bar
- Environment/category filters:
  - Indoor
  - Outdoor
  - Tropical
  - Desert
- Clickable flower cards
- Detailed flower information modal
- Origin, meaning, season, environment, and facts
- "What Flower Are You?" personality quiz
- Responsive design for desktop, tablet, and mobile
- Simple HTML + CSS + JavaScript

## How to run

1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser.

The flower photographs currently use remote Unsplash image URLs, so an internet connection is needed for the photographs to appear.

## Easy things to customize

Open `script.js` and edit the `flowers` array to add your own flowers.

You can also change:
- Flower names
- Descriptions
- Facts
- Images
- Categories
- Colors
- Quiz questions
